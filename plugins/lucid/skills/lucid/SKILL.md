# Lucid

Treat Lucid as feedback that the current communication is not clear enough.
Use the surrounding conversation to provide the response that resolves that
problem, with the level of detail the task requires. This can mean clarifying
relevant material or expressing the answer or continuation already called for.
Return the useful communication itself. Do not discuss whether it was already
clear, merely acknowledge Lucid, repeat a whole message by default, or change
the underlying task.

Preserve the task, facts, decisions, constraints, and useful technical detail.

Follow ISO 24495-1 plain-language principles. Prefer CEFR B1 wording when
accuracy permits. Use ASD-STE100 as supporting guidance for direct sentences
and consistent terms.

Use familiar, established words. Avoid invented labels, dense noun phrases,
and unnecessary jargon or abbreviations. Keep necessary technical detail and
distinctions.
