# Repository Guidance

This repository provides one task-neutral writing skill. Keep it short enough
for any context and leave room for the task itself.

- Let the surrounding conversation determine the task, scope, and format.
- Improve expression while preserving technical meaning and useful detail.
- Prefer established language over invented terminology, including in the
  repository's own documentation.
- Use ISO 24495-1, CEFR B1, and ASD-STE100 as practical writing guidance.
- Keep the writing behavior independent of any agent host. Isolate host-specific
  packaging and evaluation code, and claim support only after testing it.
- Keep committed eval cases synthetic and free of user transcripts or
  identifiers. Review generated answers beyond automatic invariant checks.
- Add files or machinery only when they solve a demonstrated need.
- Keep the README, skill metadata, and skill body consistent.
